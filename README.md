# 课程作业管理器

一个用于管理**课程**与**作业**、展示**整学期课表**、并在作业截止前**自动提醒**的图形界面程序。
纯前端实现（HTML + CSS + 原生 JavaScript），零第三方依赖，离线可用。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 课表 | **周视图**：按「时间段 × 星期」生成单周课表，表头带日期、今天高亮，同一时段多门课并排显示；**周次导航**：上一周 / 下一周 / 下拉任选一周 / 回到本周；**整学期总览**：一屏看完整个学期每一周的安排，点任意周次即跳到该周详情；**学期设置**：设置第 1 周周一与总周数（1–40 周） |
| 周次规则 | 每个上课时间段可单独指定周次：`1-16`、`1,3,5-8`、`1-16(单)`、`1-16(双)`、`单周`、`双周`，留空表示每周都上；同一门课可有多个时间段、不同周次 |
| 作业 | 新增 / 编辑 / 删除作业，关联课程、截止时间、优先级（高/中/低）、状态（未开始 / 进行中 / 已完成）、备注；支持关键字搜索、按课程 / 状态筛选、按截止时间 / 优先级 / 创建时间排序 |
| 课程 | 课程名称、任课教师、上课地点、学分、课表颜色，以及任意多个上课时间段（星期 + 起止时间 + 周次）；删除课程时其作业自动转为「未分类」，不会丢数据 |
| 截止提醒 | 倒计时实时显示（剩余 3小时20分 / 已逾期 2小时），按紧急度分级着色（逾期 / 紧急 / 今日内 / 3天内 / 较宽松）；到达设定时间点弹出页面提示条 + 提示音 + 系统桌面通知；顶部横幅常驻显示 24 小时内与已逾期的作业 |
| 统计 | 课程数、时段数、**本周课次**、待完成作业、24 小时内截止、已逾期、已完成、总学分；后台标签页时浏览器标题会显示 `(待办数)` 提醒 |
| 数据 | 自动保存到浏览器 localStorage，支持导出 / 导入 JSON 备份、载入示例数据、一键清空 |
| 运行环境 | 启动时自动自检（Node 版本 / 必需文件 / 浏览器能力 / 关键 DOM / localStorage / 打开方式 / 通知权限）；缺环境时给出「缺什么 + 怎么装」，可在设置页随时复查或复制诊断信息 |
